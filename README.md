I'm a full-stack engineer who usually ends up as the sole engineer on what I build, architecture through what happens after it ships. Lately that's meant production GenAI: multi-tenant RAG, agentic workflows, model gateways, and making sure AI output is actually correct before someone relies on it, on top of the Laravel/PHP and Python full-stack work I started with.

A few things I've actually shipped:

- A **multi-tenant RAG platform** live inside a third-party school ERP, with metadata-scoped retrieval, a multi-provider LLM gateway with automatic failover, and a two-pass review where a second AI pass checks the first pass's own output before a human sees it.
- An **automated financial-data QA platform** validating live ETF data across 4 regions, grown from a 38-script suite to 72 scheduled jobs and 629 check agents, with a Playwright layer that independently caught a real production bug.
- **Production marketplace platforms** on Laravel/Vue.js, with search migrated to Elasticsearch and zero-downtime blue-green index rollovers.
