## 🧩 What I actually ship

I'm usually the only engineer on what I build: architecture, backend, frontend, and what happens after it goes live. These days that means production GenAI — RAG, agentic workflows, model gateways — layered on top of the Laravel/PHP and Python full-stack work I started with.

<table>
<tr>
<td width="50%" valign="top">

### 🧠 Multi-Tenant RAG Platform
Live inside a third-party school ERP. Metadata-scoped retrieval so one tenant's data can never surface for another, a multi-provider LLM gateway with automatic failover, and a two-pass review where a second AI pass checks every finding in the first pass's own output before a human sees it.

</td>
<td width="50%" valign="top">

### 📊 Automated Financial-Data QA
Validates live ETF data across 4 regions. Grown from a 38-script suite to 72 scheduled jobs and 629 check agents, with a Playwright layer that independently caught a real, previously-undetected bug across multiple live products.

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 🏪 Production Marketplace Platforms
Laravel/Vue.js. Migrated search from SQL `LIKE` queries to Elasticsearch, blue-green index rollover for zero-downtime reindexing, Razorpay integration with idempotent webhooks.

</td>
<td width="50%" valign="top">

### 🔒 Audit-Enforced Validation Assistant
No automated detection, even at 99% confidence, becomes final without a human explicitly confirming it — enforced by an append-only audit trail at the database level, not by process.
